# Contributing to ShowMate Showcase

Thank you for your interest in ShowMate!

## Showcase Repository

Please note that this is a **showcase repository**. The actual source code for ShowMate is proprietary and closed-source. This repository exists solely to share architectural decisions, documentation, and the tech stack used in the production application.

## Pull Requests

Since there is no source code in this repository, **we do not accept Pull Requests** for code changes or features.

If you spot a typo in the documentation or have suggestions on how to improve the README or architecture documentation, feel free to open an Issue or a Pull Request!

## Security Vulnerabilities

Please **do NOT** open a public GitHub issue for security vulnerabilities. Refer to our [Security Policy](SECURITY.md) for instructions on how to responsibly disclose security issues.
