## Tips for Great Screenshots

1. **Use a real device** or the Android Studio emulator at Pixel 7 Pro dimensions
2. **Dark mode** is preferred to match the README theme
3. **Show real data**, not placeholder/lorem ipsum content
4. **Crop status bars** if they contain personal info (time, carrier, etc.)
5. Consider using tools like **AppMockup** or **Previewed** for device frame mockups

## Device Frame Mockup Tools
